Literature

Explore the 22 references collected from the tutorial glossary, exercise documentation, and presentation. They cover software testing with AI, agent design, tool use, evidence, and responsible execution.

Start with Mark Winteringham for testing practice, Anthropic's Building effective agents for workflow patterns, and OpenAI's practical guide for agent design. Documentation describes provider implementations; the tutorial uses these concepts in a tool-agnostic teaching model.
