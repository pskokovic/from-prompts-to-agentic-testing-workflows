Your goal

Build a small password-reset regression proposal that prioritizes credential protection, uses supported expectations, and makes automation dependencies explicit.

Use at most three test ideas. Setup capabilities are unconfirmed. Broader coverage may be useful but requires more setup and review.

16 minutes: 2 instruction · 5 build · 2 observe · 2 revise · 4 debrief · 1 transition. Prepared outputs and fictional examples; no AI or tests execute. Work is held in page memory only. Copy before leaving.

WorksheetScript-free branching activityEditable template
  • REQ-01: A registered user can request a password-reset link using their email address.
  • AC-01: For a registered email, send a reset link.
  • AC-02: The link expires 30 minutes after issue.
  • AC-03: A successfully used link cannot be used again.
  • AC-04: After a successful reset, the new password works and the old password does not.

Known gaps: Password policy, exact behaviour at precisely 30 minutes, unregistered-email behaviour, rate limits, multiple outstanding links, session invalidation, and delivery-time guarantees are unspecified.
