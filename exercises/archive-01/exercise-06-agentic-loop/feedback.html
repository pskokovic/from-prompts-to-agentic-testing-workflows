AGENTIC AI LOOP / FINAL MISSION

Loop design feedback

Design a workflow another person can follow without guessing.

Local simulation · No AI service connected · Nothing is sent or saved

Prepared teaching guidance; inspect the learner's written rules with a person. No score proves competence.

State strategy

Keep a source-linked evidence ledger and competing hypotheses.

Preserves provenance and contradictions across turns. It costs review effort; the controller must separate observations from its interpretations. Downstream decisions can be audited against CI-01 and returned source IDs.

Keep a compact summary plus links to the immutable evidence ledger.

Reduces prompt size while retaining the underlying evidence. Summaries can omit qualifications; review them against the linked ledger before each handoff. A summary is not independent corroboration.

Replace prior state with the latest tool response.

Keeps the prompt small but loses competing explanations, approval scope, and contradictions. A later response can silently displace CI-01. Repair the design to retain a ledger; the workshop harness still preserves history.

Returned evidence check

Check source, run/request identity, timing basis, and scope before use.

CI-01 concerns run 204/reset-204. Matching identity permits comparison with TIM-01, but does not prove every claim in a response. Retain gaps and independently review the interpretation.

Check identity and scope, then compare with existing observations.

Adds contradiction detection to provenance checks. HIST-01 repeats captured events, so agreement is not independent confirmation. This takes extra review but can expose conflicting evidence before a conclusion.

Accept any successful tool response as evidence for the failure.

Fast, but a successful retrieval can return the wrong run. CONFLICT-01 must not support run 204. Repair the gate; transport success is not evidential validity.

Recommendation threshold

Correlated timing evidence; recommend a correction with validation outstanding.

TRACE-01 with CI-01/CODE-01/TIM-01 can support a limited synchronization recommendation. Lower action cost; comparison and real implementation validation remain outstanding. This does not establish AC-04 or global service health.

Correlated timing evidence plus an approved controlled comparison.

VALID-01 illustrates a discriminating comparison and credential checks, strengthening a limited proposal. It needs scoped authority and another action. Authored results still cannot verify a real patch or all intermittent failures.

Finish when any rerun is green.

A green result alone does not identify cause or show that the test detects faults. It can conceal weak assertions. The harness will not mark this unsupported threshold recommendation-ready.

Three valid ending types

Recommendation ready: valid run correlation plus TIM-01/CODE-01 supports a limited timing explanation; add approved VALID-01 when the selected threshold requires it. Keep real validation outstanding.

Escalated: missing/mismatched evidence, unavailable authority, or repeated no progress needs a named reviewer and a specific unresolved question.

Limit reached: budget exhausted without sufficient evidence. Preserve what was learned, do not invent the missing result, and propose a human next step.

Agency and counterfactual review

A fixed read-everything sequence does not adapt to observations. A useful policy requests a correlated capture when identity is missing, then chooses comparison or a bounded handoff when correlation is established. A mismatched capture changes that decision to a targeted request or escalation. An LLM could propose these actions; the harness must still enforce permissions and limits. This activity uses participants and deterministic cards.

For the revision, compare the initial invalid-evidence rule with the revised action, information value, remaining budget, and handoff. Requesting new evidence can be defensible; immediate escalation can also be proportionate. Taking an unrelated action or accepting the mismatched capture does not resolve identity.
