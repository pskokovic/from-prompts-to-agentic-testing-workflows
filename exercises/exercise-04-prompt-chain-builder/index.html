Your goal

Prepare a small, source-backed password-reset test proposal focused on credential protection. Use the three tasks in an order you choose. For each prompt, select one block in each row, run the prepared response, and review it before continuing.

WorksheetScript-free response cardsWorked feedback
Starting sources — current requirements and known gaps
  • REQ-01: A registered user can request a password-reset link using their email address.
  • AC-01: For a registered email, send a reset link.
  • AC-02 · Release v1: The link expires 30 minutes after issue.
  • AC-03: A successfully used link cannot be used again.
  • AC-04: After a successful reset, the new password works and the old password does not.

Known gaps: Unregistered-email behaviour; password composition/length; rate limits; the exact 30-minute boundary; multiple outstanding links; session invalidation; delivery-time guarantees.
