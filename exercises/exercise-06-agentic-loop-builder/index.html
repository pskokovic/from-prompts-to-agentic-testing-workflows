Terminology: how this exercise relates to provider guides

Agentic loop: gather context, take action, and verify results, repeating as needed. A real model chooses actions from updated context; you simulate those decisions here. The harness supplies tools, retains state, and enforces controls.

Tool call → execution → tool result: requesting an action, carrying it out, and inspecting the returned observation are different responsibilities. A result becomes evidence for a claim only after its relevance and reliability are checked.

The eleven blocks and required return to assessment are this exercise’s teaching model, not a mandatory Claude or Codex architecture. Fixed workflows can also have loops; a return arrow alone does not make a system agentic. “Workflow validation failed” means the design failed a rule in this exercise.
